# Archdiocese of Roblox (AOR) - Official Website

This repository contains the source code for the official static website of the **Archdiocese of Roblox (AOR)**. 

The website serves as a central, structured online hub for the community, providing information on:
- **Leadership & Hierarchy:** Archdiocesan Curia, Clergy, and Laity structure.
- **Official Groups:** Information and links to primary affiliated groups like The Catholic Church (TCC) and the Knights of Columbus.
- **Events & Announcements:** A calendar of upcoming masses, ordinations, and community gatherings.
- **Gallery:** A collection of screenshots and memories from formal ceremonies and masses.

## Tech Stack
This is a lightweight, responsive static website built using:
- **HTML5** for semantic structure.
- **Vanilla CSS3** (CSS Variables, Flexbox, Grid) for formal, diocesan-inspired styling.
- **Vanilla JavaScript** for mobile navigation and scroll animations.

## Getting Started
To view the website locally, simply download the files and double-click on `index.html` to open it in any modern web browser. No local server or build tools are required.
